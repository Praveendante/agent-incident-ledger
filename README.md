# Agent Incident Ledger

A public record of what AI agents have actually done, one file per incident.

Each entry answers the same five questions, in the same order, from primary
sources only:

1. What was the agent told to do?
2. What did the text layer see?
3. What did the tool actually do?
4. Where is the primary source?
5. Which layer would have had to check, for this to have been caught?

Entries carry no commentary, no recommendations, and nothing being sold. If an
incident has no primary source, it does not go in.

## Contributing

Open a pull request. Copy `TEMPLATE.md`, fill every field, and link a primary
source — the company's own post-mortem, the operator's own account, a court or
regulator document, or reporting that quotes one of those. Secondary coverage
that only cites other coverage is not enough.

If a field cannot be established from the source, write `not established` rather
than inferring it. An honest gap is more useful than a plausible guess, and the
whole point of this record is that you can check it.

Corrections are pull requests too. If an entry is wrong, say so with a source and
it gets fixed, with the change visible in the history.

## Counts

There is no target number. The ledger holds whatever has actually been recorded.
